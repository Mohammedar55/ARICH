# 🧠 ARICH - لعبة الذكاء والأسئلة الصعبة

تطبيق ويب تفاعلي لاختبار ذكاءك مع أسئلة متنوعة وتحديات ذهنية مشوقة!

## 🎮 المميزات الرئيسية

✨ **ثلاثة مستويات صعوبة:**
- 🟢 **سهل** - للمبتدئين
- 🟡 **متوسط** - للمتقدمين
- 🔴 **صعب** - للخبراء

⏱️ **عداد زمني:**
- 30 ثانية لكل سؤال
- حساب تلقائي للأسئلة المتخطاة

📊 **نظام النقاط:**
- +10 نقاط للإجابة الصحيحة
- -5 نقاط للإجابة الخاطئة
- حفظ تاريخ النتائج

🌙 **وضع ليلي:**
- تبديل سهل بين الوضع النهاري والليلي
- حفظ تفضيلاتك

📱 **متوافق مع جميع الأجهزة:**
- تطبيق ويب متجاوب
- يعمل على الهاتف والكمبيوتر والتابلت

## 🚀 البدء السريع

### الخيار الأول: فتح الملف مباشرة
1. قم بتنزيل المشروع
2. افتح ملف `index.html` في المتصفح
3. ابدأ اللعبة!

### الخيار الثاني: استخدام GitHub Pages
تم استضافة التطبيق تلقائياً على GitHub Pages

## 📁 هيكل المشروع

```
ARICH/

├── questions.js     # قاعدة الأسئلة (JavaScript)

```

## 🎯 كيفية اللعب

### الخطوة 1: اختيار المستوى
اختر من ثلاثة مستويات حسب مستوى ذكاءك

### الخطوة 2: الإجابة على الأسئلة
- اقرأ السؤال بعناية
- اختر الإجابة الصحيحة من الخيارات الأربع
- لديك 30 ثانية لكل سؤال

### الخطوة 3: عرض النتائج
بعد الانتهاء من 10 أسئلة:
- شاهد نقاطك النهائية
- اطلع على إحصائياتك
- لعب مرة أخرى أو اختر مستوى آخر

## 💡 الأسئلة المتوفرة

### المستوى السهل
- معلومات عامة
- أسئلة تاريخية وجغرافية
- أسئلة علمية بسيطة

### المستوى المتوسط
- أسئلة متقدمة في المعلومات العامة
- أسئلة تاريخية وثقافية معقدة
- معلومات عن التكنولوجيا والعلوم

### المستوى الصعب
- أسئلة متخصصة وصعبة جداً
- معلومات نادرة ومتقدمة
- تحديات فكرية عميقة
